# 💕 Interactive Date Invitation Website

Een prachtige, interactieve website om iemand uit te nodigen voor een date!

## Features ✨

- 🎯 **Interactieve Yes/No knop** - De "Nee" knop beweegt rond totdat je "Ja" klikt!
- 📅 **Interactieve kalender** - Kies een dag uit de volgende 4 weken
- 🚫 **Bezette dagen** - Maandag t/m donderdag zijn bezet, vrijdag en weekends zijn vrij
- 💌 **Email confirmatie** - Verzend bevestigingsemail naar jezelf en de ander
- 🎨 **Prachtig roze design** - Modern en Instagram-worthy
- 📱 **Responsive** - Werkt perfect op mobiel, tablet en desktop

## Pagina's

1. **Pagina 1: Uitnodiging**
   - Vraag met cute afbeelding
   - Yes/No knoppen

2. **Pagina 2: Kalender**
   - 4 weken kalender
   - Bezette dagen zijn grijs
   - Kies je favoriete dag

3. **Pagina 3: Email Invoer**
   - Voer je email in
   - Bevestig de geselecteerde datum

4. **Pagina 4: Succes**
   - Viering pagina
   - Confirmation dat alles is verzonden

## Setup 🚀

1. Clone dit repository
2. Open `index.html` in je browser
3. Voeg EmailJS of FormSpree toe voor email functionaliteit

## Email Setup 📧

Om emails te laten werken:

1. Ga naar [FormSpree.io](https://formspree.io)
2. Maak een account
3. Update de FormSpree endpoint in `script.js`

## Personalisatie 🎨

- Wijzig kleuren in `style.css` (`:root` variabelen)
- Pas de SVG afbeelding aan in `index.html`
- Update bezette dagen in `script.js`
